# KubeView Homebrew tap

Install the KubeView desktop app on macOS:

```bash
brew trust porkeat/kubeview
brew install --cask porkeat/kubeview/kubeview
```

KubeView is currently unsigned. Homebrew verifies the DMG checksum, but macOS may still show a Gatekeeper warning. If it does, right-click KubeView in Applications and choose Open once.
